# Pokedex

Simple pokedex made in flutter during my intership.
This project was made to learn API consuming and state management

API used: [pokeApi](https://pokeapi.co/)

**Techonologies**
- Flutter framework
- BLoc (State management)

**Features**
- Pokemon Search by name with autocomplete
- Type combination generation
- Pokemon weaknesses and advantages
- Add pokemon to favorite's list
- Filter by generation
- Change pokemon image to shiny version
- Play pokemon cry audio
- Evolution chain linked to the pokemons
